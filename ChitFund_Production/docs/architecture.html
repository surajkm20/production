Layered Architecture

The backend follows a strict 4-layer architecture. Each layer has a single responsibility and only talks to the layer directly below it.

┌─────────────────────────────────────────────────────────────┐ │ CLIENT │ │ React SPA (port 5173 / Vite) │ │ Proxies /v1 → localhost:3000 │ └────────────────────────┬────────────────────────────────────┘ │ HTTP / REST ┌────────────────────────▼────────────────────────────────────┐ │ MIDDLEWARE PIPELINE │ │ express.json → rateLimiter → authenticate → requireMember │ │ → requireAdmin → validate(zod) │ └────────────────────────┬────────────────────────────────────┘ │ ┌────────────────────────▼────────────────────────────────────┐ │ ROUTE LAYER src/routes/ │ │ Declares HTTP verbs + paths, attaches middleware & handler │ └────────────────────────┬────────────────────────────────────┘ │ ┌────────────────────────▼────────────────────────────────────┐ │ CONTROLLER LAYER src/controllers/ │ │ Reads req, calls service(s), formats and sends response │ └────────────────────────┬────────────────────────────────────┘ │ ┌────────────────────────▼────────────────────────────────────┐ │ SERVICE LAYER src/services/ │ │ Business logic, orchestration, throws AppError on failure │ └────────────────────────┬────────────────────────────────────┘ │ ┌────────────────────────▼────────────────────────────────────┐ │ DATABASE LAYER src/db/schema/ + config/db │ │ Drizzle ORM queries against PostgreSQL │ └─────────────────────────────────────────────────────────────┘
Rule: Routes never touch the database. Controllers never write SQL. Services never format HTTP responses. This keeps the layers independently testable and replaceable.

Middleware Pipeline

Every incoming request passes through these layers in order before reaching a controller.

express.json()

Parses JSON request bodies. Applied globally to all routes.

rateLimiter

General API: 100 requests / 15 min per IP. OTP endpoints: 5 requests / hour — prevents SMS/brute-force abuse.

authenticate

Verifies the Authorization: Bearer <token> header. On success, attaches the decoded user to req.user. Skipped on public auth routes.

requireMember

Queries memberships table for req.params.groupId + req.user.id. Attaches req.membership or throws 403. Applied to all /groups/:id/* routes.

requireAdmin

Checks req.membership.role === 'Admin'. Applied only to admin-only endpoints (group management, member CRUD, cycle operations).

validate(schema)

Zod parse on req.body, req.params, or req.query. Throws a structured 422 error on failure — controllers always receive clean, typed data.

→ Controller Handler

Route handler executes. Calls service layer, sends { data } response.

errorHandler (global, last)

Catches anything thrown. Maps AppError → HTTP status + code. Maps ZodError → 422. All unknown errors → 500. Sends { error: { code, message, details } }.

Money & Ledger Design

💰

Integer Paise

All monetary values stored as BIGINT in paise. ₹1 = 100 paise. Eliminates floating-point rounding errors entirely. UI layer uses formatPaise() to convert for display.

📒

Append-Only Ledgers

basket_transactions and loan_transactions are never updated or deleted. Every balance change creates a new row with balance_after — fully auditable history.

🗄️

Balance Cache

baskets.current_balance is a pre-computed cache for fast reads. It is updated atomically whenever a basket transaction is written — no full-table sum on every request.

⏱️

Interest Accrual

A node-cron job runs on schedule, writes ACCRUAL rows to loan_transactions, and updates loans.total_interest_paid. Never touches principal rows.

Key Architectural Patterns

Schema-First Validation

Every API input is validated by a Zod schema before reaching the controller. Invalid payloads never enter the service layer.

Centralized Error Handling

AppError carries an HTTP status + machine code. The global errorHandler middleware maps all thrown errors to a uniform JSON envelope.

Authorization Middleware Chain

authenticate → requireMember → requireAdmin forms a composable guard chain. Each middleware enriches req for the next layer.

Integer Money (Paise)

All monetary arithmetic uses integer paise. No floats touch financial data. Display conversion happens only at the UI boundary.

Append-Only Ledger

Basket and loan balances are built from immutable transaction rows. Historical state is always recoverable. No UPDATE/DELETE on financial records.

Balance Cache + Recomputation

baskets.current_balance is a denormalized cache updated atomically per transaction. Falls back to ledger recomputation if ever diverged.

Cursor-Based Pagination

Lists use cursor pagination (not offset) for consistent performance on large datasets and to avoid skipped/duplicate rows on concurrent writes.

Polymorphic Audit Log

audit_logs(entity_type, entity_id) tracks changes across payments, cycles, memberships, and loans in a single table without foreign key coupling.

Type-Safe DB Layer

Drizzle ORM provides full TypeScript inference from schema. No raw SQL strings in controllers or services — type errors catch schema mismatches at compile time.

Env Validation on Boot

config/env.ts uses Zod to parse all environment variables at startup. Missing or malformed config crashes fast with a clear error — never silently at runtime.
